Mid Software Engineer — Backend (Python / FastAPI)

As a Mid-level Backend Engineer, you will build and maintain features across our HRIS
platform using Python & FastAPI. You will own well-defined modules end to end, write
clean and tested code, and grow your skills alongside senior engineers.

**Key Responsibilities**

- Develop and maintain backend services and REST APIs using FastAPI and Python.
- Implement features for HRIS modules (attendance, leave, employee records,
  notifications) with clean, maintainable code.
- Write efficient database queries and contribute to data model design in PostgreSQL.
- Participate in code reviews, testing, and debugging to ensure quality.
- Collaborate with frontend, QA, and product teams to deliver features.
- Contribute to API integrations and background jobs.

**Required Qualifications**

- 2–4 years of professional backend development experience.
- Solid proficiency in Python and hands-on experience with FastAPI (or Flask/Django
  with willingness to work in FastAPI).
- Working knowledge of SQLAlchemy, Pydantic, and async concepts. Good experience with
  PostgreSQL and writing efficient queries.
- Understanding of REST API design and authentication (JWT/OAuth2).
- Familiarity with Docker, Git, and testing (pytest).
- A quick learner who is highly inquisitive and eager to explore and adopt evolving
  technologies.

**Nice to have**

- Experience with Redis / Celery.
- Exposure to gRPC / Protocol Buffers for inter-service communication.
- Exposure to SaaS or HR/Payroll domain.
- Basic cloud exposure.
- Willing to adopt new tech stack as per project requirements.
